LABX REMOTE

Terminal-First Experiment Distribution & Execution Backend

Static API v1.0.0

Quick Install & Usage

Download individual experiments or entire collections directly into your terminal:

# 1. Download and run an individual experiment
labx download 3
labx run 3

# 2. Download all experiments in one command
labx download all

Available Static Endpoints

  • /catalog.json — Complete experiment catalogue API
  • /version.json — Host version metadata
  • /downloads/labx_experiments.zip — Full experiments archive
